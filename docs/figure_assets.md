# Manuscript figure assets

The manuscript-facing figures under `figures/manuscript/` were regenerated from the compact completed result tables using the plotting code in this repository.

Presentation updates include:

- Figure 2: median + IQR + 95th percentile, with a numerical MAPQ table available separately.
- Figure 5: cividis palette plus cell counts.
- Figures 6–8: run IDs on the vertical axis and the filtering conditions shown as separate markers for readability.

The figure assets correspond to the compact result summaries distributed with this release. Figure numbering and legends should be kept synchronized with the manuscript.
