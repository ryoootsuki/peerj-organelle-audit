# Metadata files

- `bioproject_protocol_metadata_curated.tsv`: publication-curated BioProject-level protocol information.
- `bioproject_strategy_overrides.tsv`: explicit, source-attributed correction of archive-derived strategy labels used in derived analyses.
- `protocol_sources.tsv`: primary-publication DOI map used for curation.
- `BioProject_protocol_metadata_curated_source.tsv`: preserved human-readable table from the revision package; retained for audit history.

The raw SRA/ENA manifests remain under `manifests/` and are not rewritten.
